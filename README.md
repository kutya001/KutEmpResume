# Омуралиев Кутман — резюме

Сайт-резюме Data-аналитика: опыт, проекты, навыки и PDF на трёх языках (RU / KG / EN).

🔗 **[kutya001.github.io/KutEmpResume](https://kutya001.github.io/KutEmpResume/)** · визитка с услугами: [kutya001.github.io/My-Services](https://kutya001.github.io/My-Services/)

## Что на сайте

- **SQL-терминал** на первом экране: печатает запрос к «базе карьеры» и показывает ответ — текущую должность, сильные навыки и миссию.
- **Карьера как диаграмма Ганта**: полосы прорисовываются при прокрутке, преподавание идёт отдельным цветом; клик по полосе открывает карточку.
- **Проекты**: мини-схема задача → решение → результат, со стеком; шаги схемы появляются по очереди.
- **Образование и курсы** — линия времени: годы загораются, карточки вуза выплывают сверху, курсы — снизу.
- **Навыки с фильтром**: клик по навыку показывает, где он применялся, и подсвечивает опыт и проекты.
- **Три темы** (Белый / Тёмный / Тёплый) с плавной сменой, три языка; та же верхняя панель — на визитке.
- **Все разделы анимированы** при прокрутке (выплывают, проявляются из размытия); при настройке «Уменьшить движение» всё показывается сразу.
- **PDF-резюме** на одном листе A4 с фото и логотипами мест работы — генерируется автоматически при каждом деплое.
- Кнопка «Сохранить контакт» (vCard), превью ссылки для мессенджеров, иконка сайта.

## Как обновлять

| Что | Где |
|---|---|
| Новая работа, даты, навыки | `src/shared/career.json` — даты в формате `ГГГГ-ММ`, у текущего места `"end": null`. Подписи дат, стаж («6+ лет») и счётчики считаются сами. Визитка подтягивает этот файл с сайта резюме автоматически. |
| Проекты | `src/projects.json` (поле `skills` — id навыков из career.json) |
| Тексты интерфейса | `src/data.json` (ru / kg / en) |
| LinkedIn | `PERSON.linkedin` в `src/shared/site.js` — кнопка появится на обоих сайтах |
| Анонимная статистика | `GOATCOUNTER_CODE` в `src/shared/analytics.js` |

Папка `src/shared` одинаковая в обоих репозиториях — после правки скопируйте её в `My-Services`.

### Ссылки с меткой

- `?lang=en` / `?lang=kg` — откроет сайт сразу на нужном языке.
- `?src=hh`, `?src=tg`, `?src=linkedin` — источник перехода попадёт в уведомление о просмотре.

## Запуск

```bash
npm install
npm run dev        # разработка
npm run build      # сборка в dist/
npm run pdf        # PDF-резюме в dist/ (нужен браузер: npx playwright install chromium)
```

Деплой — GitHub Actions (`.github/workflows/deploy.yml`) при пуше в `main`: сборка, PDF, публикация на GitHub Pages.

## Стек

React 19, Vite 5, Tailwind CSS 3, Font Awesome (локально), Playwright (только для PDF).
